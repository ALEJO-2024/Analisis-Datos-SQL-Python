# 📊 Análisis Integral de Datos: SQL & Python

Repositorio enfocado en demostrar el flujo completo de análisis de datos: desde la extracción y consulta de información en bases de datos relacionales hasta la limpieza, transformación y análisis exploratorio utilizando Python.

---

## 🛠️ Tecnologías y Herramientas
* **Bases de Datos:** MySQL
* **Lenguajes & Librerías:** Python, Pandas, NumPy
* **Control de Versiones:** Git & GitHub

---

## 📂 Estructura del Repositorio

El proyecto está organizado de la siguiente manera para mantener un código limpio y escalable:

```text
📁 analisis-datos-sql-python/
│
├── 📁 sql/                 # Scripts con consultas y lógica de base de datos
│   ├── consultas_ventas.sql
│   └── kpis_negocio.sql
│
├── 📁 python/              # Scripts de procesamiento y análisis de datos
│   ├── limpieza_datos.py
│   └── analisis_exploratorio.ipynb
│
├── 📁 data/                # Muestras o datasets anonimizados (cuando aplica)
├── .gitignore              # Archivos excluidos del control de versiones
└── README.md               # Documentación principal del proyecto
